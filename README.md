# Evan Thalheimer

The landing page at **https://nave1294.github.io/**: about me, a headshot, and
one question that sends visitors to the right site:

- Ilevan Scanning: https://nave1294.github.io/ilevan-scanning/ (repo `ilevan-scanning`)
- Portfolio: https://nave1294.github.io/portfolio/ (repo `portfolio`)
- Contact: `contact.html`, phone and email

Plain HTML and CSS at the top of the repo (`index.html`, `css/`, `assets/`),
no build step, so Pages can serve it straight from `main` (or deploy it with
the GitHub Actions workflow). `.nojekyll` stops GitHub's Jekyll from touching
it. To add a site, add an answer to the list in `index.html`.
